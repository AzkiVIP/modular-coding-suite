# Changelog

## Prepared repository update — v1.0.0 (no version bump)

This prepared source package keeps the project/plugin version at `1.0.0` as requested. It does not modify the already-published `v1.0.0` Git tag or release assets.

- Refines the existing `ui-ux-design` skill with explicit product/brand evidence categories (confirmed, inferred, proposed).
- Adds contextual use of the Impeccable Slop Catalog and official shadcn/ui component documentation without treating patterns as universal bans or forcing a framework/dependency change.
- Preserves the ten-skill division of responsibilities and synchronizes the updated UI/UX skill into the Claude Code distribution.
- Includes the research notes, acceptance brief, evaluation prompts, rubric, smoke-test examples, and an honest validation report.
- Keeps the existing Apache License 2.0 and expands the README with usage and evaluation documentation.

## [1.0.0 — Initial public release](https://github.com/AzkiVIP/modular-coding-suite/releases/tag/v1.0.0)

This release consolidated the intended baseline after internal development and Task Board experiments.

- Includes ten modular skill guides, with orchestration and selective specialist routing.
- Establishes a positive UI/UX quality bar while avoiding generic, decorative-by-default interfaces.
- Includes regression guidance for CSS cascade issues such as search icon/text overlap.
- Strengthens guidance for persisted-data validation, storage failure honesty, keyboard-focus continuity, and evidence-based tests.
- Includes a separate Claude Code plugin distribution while retaining portable source skill files.

Previous `1.1.0` and `1.1.1` archives were internal development snapshots and are not public releases.

# Changelog

## [1.0.0 — Initial Public Release](https://github.com/AzkiVIP/modular-coding-suite/releases/tag/v1.0.0)

Establishes the baseline for Modular Coding Suite with ten modular skill guides, orchestration, and selective specialist routing.

- Provides ten specialized skills with clearly divided responsibilities and portable source files.
- Establishes UI/UX quality standards that favor purposeful, context-sensitive design over generic, decorative-by-default interfaces.
- Refines `ui-ux-design` with explicit distinctions between confirmed, inferred, and proposed product or brand details.
- Adds contextual guidance for using the Impeccable Slop Catalog and official shadcn/ui documentation without treating design patterns as universal rules or requiring framework changes.
- Includes practical guidance for CSS regression issues, persisted-data validation, storage failure handling, keyboard-focus continuity, and evidence-based testing.
- Provides a separate Claude Code plugin distribution.
- Includes supporting documentation such as research notes, an acceptance brief, evaluation prompts, a rubric, smoke-test examples, and a validation report.
- Documents usage and evaluation procedures in the README and retains the Apache License 2.0.

**Repository maintenance:** Improvements made after the initial release are included in the repository while the project and plugin version remain `1.0.0`. The existing `v1.0.0` Git tag and published release assets remain unchanged.

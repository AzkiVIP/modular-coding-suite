# Changelog

## 1.0.0 — Initial public release

This release consolidates the intended baseline after internal development and Task Board experiments.

- Includes ten modular skill guides, with orchestration and selective specialist routing.
- Establishes a positive UI/UX quality bar while avoiding generic, decorative-by-default interfaces.
- Includes regression guidance for CSS cascade issues such as search icon/text overlap.
- Strengthens guidance for persisted-data validation, storage failure honesty, keyboard-focus continuity, and evidence-based tests.
- Includes a separate Claude Code plugin distribution while retaining portable source skill files.

Previous `1.1.0` and `1.1.1` archives were internal development snapshots and are not public releases.
